# Topic: Evasion, bypass, and detection avoidance

## Meta-Summary

The records portray evasion as a broad systems problem rather than a narrow contest over malware signatures. Across endpoint security, AI agents, identity verification, hardware mitigations, application filters, surveillance, cloud infrastructure, and physical controls, the recurring pattern is that defenders observe or enforce only one representation of an action while attackers operate through another. Examples include using signed remediation drivers instead of vulnerable third-party drivers, COM or WinRT instead of monitored command-line tools, GPU-private memory instead of CPU-visible mappings, legitimate cloud relays instead of suspicious C2 infrastructure, and tool invocation paths that bypass an LLM entirely.

Several records argue that apparently strong defenses fail because of architectural blind spots: inconsistent Unicode transformations, signal handling outside hardware CFI checks, race windows in container policy deployment, unobservable external state, client-controlled biometric media pipelines, or model gateways that lack execution context. Other records focus less on suppressing alerts than on blending into legitimate administrative activity or actively misleading analysts. The most novel example, SEND, treats the SOC’s causal narrative and triage behavior as an attack surface rather than merely trying to avoid telemetry [record_id:2997].

The collection is dominated by 2026 conference abstracts from Black Hat, DEF CON, and BSides Las Vegas. It contains many demonstrations, tool announcements, workshops, and prospective claims, but relatively little independently verifiable evaluation data. Strong evidence is concentrated in records that describe concrete architectures, vulnerabilities, test sets, disclosures, patches, or reproducible tools. Claims such as “100% evasion,” “every app fell,” or “effectively impossible to firewall” should be treated as presenter assertions pending access to code, datasets, recordings, and vendor responses.

## Research Landscape

The landscape spans five overlapping areas.

First, Windows endpoint evasion is especially prominent. The records examine EDR assumptions about process ancestry, signed drivers, protected processes, command-line telemetry, COM, WinRT, WMI, application packaging, and kernel privileges. Rather than relying only on custom malware, many techniques reuse trusted Microsoft components or default operating-system subsystems [record_id:2611] [record_id:2622] [record_id:2862] [record_id:2866] [record_id:2870] [record_id:2936] [record_id:2950] [record_id:2953].

Second, the collection has a substantial body of mitigation-bypass research. Hardware CFI, shadow stacks, Spectre defenses, BPF JIT blinding, PHP heap hardening, Apple kernel protections, mobile sandboxes, and secure boot are all challenged through gaps between the intended security model and actual implementation paths [record_id:2607] [record_id:2610] [record_id:2632] [record_id:2680] [record_id:2687] [record_id:2863] [record_id:2893] [record_id:2908] [record_id:2911].

Third, AI security records show a shift from simple jailbreak prompts toward attacks on agent architecture, tool routing, code execution, long-term memory, external content, and model-mediated security decisions. Some talks attack prompt classifiers; others bypass or escape the surrounding sandbox without persuading the model at all [record_id:2641] [record_id:2655] [record_id:2662] [record_id:2798] [record_id:2871] [record_id:2887] [record_id:2925] [record_id:3073] [record_id:3103].

Fourth, identity and authenticity controls are repeatedly shown to be vulnerable at their inputs or trust anchors. The records cover MFA phishing, biometric KYC and liveness checks, counterfeit TPM identity, first-party phishing channels, facial-recognition evasion, North Korean signature controls, and generative-content watermark removal [record_id:2650] [record_id:2859] [record_id:2884] [record_id:2909] [record_id:2915] [record_id:2917] [record_id:2941] [record_id:2942] [record_id:3120].

Finally, several records extend evasion into less conventional domains: USB HID operations, counter-drone detection, medical imaging, physical badge systems, game anti-cheat and DRM, and human conditioning [record_id:2729] [record_id:2746] [record_id:2998] [record_id:3000] [record_id:3003] [record_id:3013] [record_id:3019] [record_id:3021] [record_id:3096].

## Major Themes And Trends

### Trusted infrastructure is becoming an offensive substrate

The strongest cross-cutting theme is that attackers increasingly obtain stealth by using the same mechanisms defenders are expected to trust. The BTR research reverse-engineers Microsoft Defender’s signed Boot-Time Removal driver and claims it can be supplied with valid encrypted transactions to perform attacker-chosen file and registry operations from Ring 0. Its significance is that the method does not fit conventional Bring Your Own Vulnerable Driver logic: the component is built into Windows, signed by Microsoft, and operating as designed [record_id:2611]. The same work appears in a closely matching DEF CON record [record_id:2866].

Bring-Your-Own-EDR similarly proposes weaponizing an EDR installer and its trust relationship with Protected Process Light to create self-protected malware [record_id:2870]. Related work chains execution in WerFaultSecure with a Microsoft System Guard driver to gain privileged process-tampering primitives [record_id:2953]. These talks collectively challenge a widespread defensive heuristic: that vendor signing, protected-process status, or association with security software implies benign intent.

At a higher layer, COM, WinRT, WMI, and Windows packaging expose capabilities that overlap with well-monitored command-line tools but produce different telemetry. Surrogate Ghost creates random, short-lived COM identities, activates them through DCOM, and removes the registry artifacts within milliseconds, frustrating static CLSID blocklists and process-lineage analysis [record_id:2622]. Another study routes package installation, code execution, module loading, and network communication through COM and WinRT instead of PowerShell, winget CLI, or conventional socket paths [record_id:2936]. Custom WMI providers placed remotely through MS-WMIO run inside WMIPrvSE.exe rather than through the heavily monitored Win32_Process path [record_id:2862]. The MSIX research broadens this pattern across URL handlers, AppContainers, package identity, WMI providers, and DCOM objects [record_id:2950].

The same principle appears outside Windows. Administrative Living-off-the-Land uses CI/CD runners, IAM workflows, cloud control planes, and security tooling so that compromise resembles ordinary DevOps administration [record_id:2718]. Cloud relay services from Microsoft and Amazon provide trusted domains and outbound HTTPS paths that organizations cannot easily block without disrupting business operations [record_id:3040]. First-party Microsoft services can allegedly be made to send attacker-controlled phishing pretexts from trusted infrastructure [record_id:2941]. The broad trend is a move from “living off the land” binaries to living off trusted APIs, service planes, installers, identity systems, and security products.

### Evasion exploits gaps between security layers

Many records describe defenses that are individually reasonable but disagree about representation, timing, or state. Unicode is the clearest application-layer example. Different treatment by decoders, WAFs, frameworks, databases, browsers, and LLM preprocessors can change meaning as data moves through a pipeline. The cited consequences include validation bypass, filtered-character generation, cookie-prefix bypass, XSS or RCE, LLM jailbreaks, and concealment of supply-chain malware [record_id:2604].

Container syscall defenses show the same problem in time. Stateless filtering cannot recognize malicious sequences, asynchronous process termination may occur after a damaging syscall has completed, and delayed policy installation creates an initialization window. The proposed defense combines thread-level sequential evaluation, inline LSM-BPF blocking, and OCI-hook policy injection [record_id:2617]. This is one of the few records that pairs bypass analysis with a concrete replacement architecture.

Kernel and hardware mitigations are repeatedly bypassed through execution paths outside the mitigation’s assumed boundary. ARM64 PAC and BTI validate branches, but sigreturn restores user-controlled execution context without passing through an ordinary validated branch [record_id:2607] [record_id:2893]. Segmentation Fault-Oriented Programming similarly uses repeated signal faults to progress attacker-controlled execution under Intel CET [record_id:2863]. Shadow-stack research describes three direct-write mechanisms involving `/proc/self/mem`, ptrace, userfaultfd, and WRSSQ, with one path reportedly prompting a Linux patch [record_id:2911]. Spectre v2 research attacks the assumption that predictor state remains neutralized between sanitization and use [record_id:2632].

Other implementation gaps include a BPF instruction introduced after the constant-blinding logic was written [record_id:2610], weak primitives that remain exploitable under PHP’s newer heap protections [record_id:2680], and bug chains selected specifically to survive Apple’s MTE, PAC, kalloc_type, and SPTM mitigations [record_id:2687]. These records suggest that additive defenses are brittle when enforcement is fail-open, instruction sets evolve, or exceptional control paths are not modeled.

### Endpoint evasion is shifting from process hiding to telemetry substitution

Traditional EDR evasion often focuses on hiding injection, syscalls, or C2. That remains visible in the hands-on workshop using module stomping, call-stack spoofing, indirect syscalls, Havoc customization, and BYOVD to iteratively bypass Elastic Defend [record_id:2750]. Driver vulnerability research likewise covers kernel-level EDR and antivirus disabling [record_id:2763].

However, newer records emphasize changing the source or location of telemetry. A double-fork can defeat PID-ancestry tracking for AI-agent child processes [record_id:2655]. Ephemeral COM can sever lineage and place execution in legitimate-looking `dllhost.exe` trees [record_id:2622]. WMI providers execute inside an expected host process [record_id:2862]. COM and WinRT avoid logging tied to familiar CLI interfaces [record_id:2936]. On macOS, private Metal GPU buffers allegedly place encoded payloads outside Mach VM and Endpoint Security mmap visibility, reducing CPU-visible exposure to brief staging intervals [record_id:2897]. PhantomShell goes further at the network layer by constructing raw TCP responses associated with existing services, making its C2 traffic appear to belong to already open ports [record_id:3099].

Obfuscation remains part of the picture. Lyra transforms Rust LLVM IR with string encryption, block shuffling, and indirect branches, with demonstrations claiming that YARA rules matching unobfuscated builds fail against transformed and randomized outputs [record_id:2784]. DICOM polyglots are presented as payload carriers that can survive AV, EDR, and content inspection in healthcare environments [record_id:3019].

### AI evasion is moving beyond “ignore previous instructions”

The AI records repeatedly reject a flat view of jailbreaks. The retail-agent compromise used a product-comparison path to reach untrusted content, discovered that a search-query parameter bypassed the intent classifier, extracted internal prompt and tool syntax, and then induced backend tool execution [record_id:2641]. CoreBreak claims that some managed-agent SDK paths can skip the model and guardrails entirely and invoke tools directly [record_id:2662]. Both imply that model-level safety is irrelevant when orchestration paths bypass it.

AI coding environments create a related containment problem. Roblox’s internal testing found that hidden instructions could cause Claude Code to exfiltrate credentials through processes and network requests that looked legitimate to EDR. Its response combined OS sandboxes, an ML gateway, controlled prompts, and network isolation, but testing still found persistence and ancestry-tracking escapes [record_id:2655]. A cross-vendor analysis of Claude Code, Gemini CLI, and Codex CLI argues that each sandbox rests on a runtime assumption that can be deterministically violated [record_id:2887]. Copilot Studio research describes a chain through Python introspection, `pythonnet`, and a nondeterministic LLM guardrail whose leaked reasoning acted as an attacker oracle [record_id:2925]. A national-security-oriented discussion warns that classical containers may be inadequate if capable agents can discover new kernel vulnerabilities [record_id:3129].

Other work studies the classifier itself. CerBERTus separates harmfulness, goal, and framing into three supervised heads, reporting high AUC on held-out harm categories and jailbreak framings [record_id:2778]. Anthropic’s policy-oriented talk describes four cyber-use categories, intentionally accepts more false positives for a larger safety margin, and proposes a Cyber Jailbreak Severity framework [record_id:3093]. MPG automates mutation of cross-prompt-injection payloads to discover variants that still evade safeguards [record_id:3073].

The records also anticipate more patient and semantically subtle attacks. Agentic browser research combines prompt injection, memory poisoning, guardrail manipulation, CSRF, font-based injection, and conventional RCE [record_id:2798]. The “Agent Long Con” argues that single malicious pages increasingly fail and that attackers may need cumulative steering and poisoning over time [record_id:3103]. DarkSyringe embeds clinically plausible falsehoods into PDFs rather than overtly conflicting instructions, aiming to remain semantically indistinguishable from real medical content [record_id:3082]. LGTM bypasses an LLM build gate not by hiding malicious content from the model, but by placing the decisive danger in a location the model cannot inspect [record_id:2871].

### Identity defenses fail when the capture pipeline or trust anchor is attacker-controlled

Mobile biometric records argue that liveness and anti-deepfake models are only as reliable as the client-side frame pipeline supplying them. One kill chain combines kernel-level root concealment, Frida hooks, YUV-frame replacement, KYC payload substitution, and synthetic faces [record_id:2884]. A separate six-month study reports physical spoofs and cross-process buffer hijacking against biometric frameworks, framing RASP, kernel integrity, and AI liveness controls as “client-side theater” when the media source can be hooked [record_id:2909]. Both report universal or near-universal success, but neither abstract provides enough sample details to establish generality.

MFA-resistant phishing is similarly attacked by controlling the browser rather than merely proxying requests. One architecture uses Chrome DevTools Protocol rendering and MHTML snapshots to preserve legitimate script execution while neutralizing CSP and SRI compatibility problems, then hooks APIs to capture post-MFA tokens [record_id:2859]. Persistent Browser-in-the-Middle work adds keystroke capture, file modification, continued access after logout, and socially engineered camera or microphone access [record_id:2942].

Hardware identity can also be counterfeited. A low-cost FPGA-based SPI TPM is claimed to appear to Windows 11 as a trust anchor, raising questions for measured boot, attestation, anti-cheat, and AI infrastructure [record_id:2915]. In North Korea’s controlled handset ecosystem, the Pigeon self-signature spoof reportedly bypasses state signature verification, while related work examines hidden screenshots, forensic tooling, media obfuscation, and anti-forensics [record_id:2917].

Facial-recognition avoidance attacks the model rather than the identity protocol. noRecognition uses a genetic algorithm and a library of adversarial methods to evolve textile patterns targeting person detection, face detection, and recognition across ten models [record_id:2650]. Its DEF CON counterpart emphasizes a live scarf demonstration and names commercial surveillance contexts [record_id:2889]. Generative-content provenance is another identity-like control: regeneration and surrogate-model attacks reportedly remove Google SynthID detection, with a stated 100% rate over 104 held-out images [record_id:3120].

### Detection avoidance can mean deceiving the analyst, not the sensor

SEND is the clearest conceptual expansion of the topic. It proposes generating genuine but low-cost telemetry—failed credential reads, dummy transfers, or ransomware-like file creation—to consume analyst attention and poison incident narratives. An LLM-based consistency engine would coordinate telemetry and planted artifacts into a coherent false explanation, while the proposed Investigation Narrative Divergence Reward measures errors in event reconstruction, causal structure, intent, and attribution [record_id:2997]. This differs from conventional evasion because the defender may see every event and still misunderstand the operation.

The “Human EDR” talk makes an analogous argument at the user layer: security training can create predictable pattern matching that attackers evade by omitting familiar phishing cues or exploiting behavioral conditioning inherited from prior employers [record_id:3003]. Administrative Living-off-the-Land makes intent itself the difficult classification problem when every action is a legitimate API call [record_id:2718]. Collectively, these records suggest that the next detection frontier is semantic and contextual, not simply broader telemetry collection.

## Methods, Tools, And Approaches Discussed

The endpoint-oriented records use a mixture of custom loaders, indirect syscalls, process-lineage disruption, signed-driver abuse, WMI provider installation, transient COM registration, and alternate Windows API surfaces. Named tools or frameworks include BTR_CLI for constructing Defender BTR transactions [record_id:2611] [record_id:2866], Surrogate Ghost for ephemeral COM activation [record_id:2622], Lyra for cargo-native Rust obfuscation [record_id:2784], and customized Havoc loaders and C2 components used in an EDR workshop [record_id:2750]. Other records propose WMI provider libraries [record_id:2862], COM/WinRT-based package and networking primitives [record_id:2936], and Mythic transport profiles for Azure Relay and AWS IoT [record_id:3040].

Mitigation-bypass methods include crafted signal frames and CFI-safe stack pivots on ARM64 [record_id:2607] [record_id:2893], fault-driven execution under CET [record_id:2863], direct shadow-stack writes [record_id:2911], manual post-compilation BPF-bytecode modification [record_id:2610], one-shot heap feng shui and zval-oriented programming in PHP [record_id:2680], and userspace process virtualization with selective CPU emulation on iOS [record_id:2908]. Secure-boot and pre-OS work reverses signed EFI components to establish execution before EDR and OS controls load [record_id:2753]. A separate Android exploit chain starts at an audio decoder, escapes the media sandbox, and reaches kernel access without user interaction [record_id:2643].

AI-testing methods range from structured factorial datasets to mutation frameworks and architecture review. CerBERTus crosses goals with framing styles to distinguish harmful intent from rhetorical wrapper [record_id:2778]. MPG generates mutated prompt-injection variants [record_id:3073]. The AI-sandbox records recommend identifying the actual containment primitive, reading enforcement code, and testing runtime assumptions rather than treating prompt injection as the only threat [record_id:2887]. Roblox’s architecture adds managed prompts, an ML gateway, VPN restrictions, and isolated environments across multiple operating systems [record_id:2655].

Physical and RF methods include programmable USB HID payloads, C2 integration, geofencing, and operational-security practices using O.MG hardware and DuckyScript [record_id:2729]. Counter-UAS records examine Remote ID reception and forgery, RF range limitations, jamming side effects, takeover constraints, and drones that evade radio detection through cellular, fiber, or autonomy [record_id:2746] [record_id:3000]. Badge-access research proposes forcing verification to a lower tier and denying card use with low-cost hardware [record_id:3021].

In games, anti-cheat work relocates sensitive Unity fields across struct boundaries at compile time to frustrate memory hacks [record_id:2998], while SLP Enforcer supports retrospective investigation of Super Smash Bros. Melee cheating [record_id:3096]. A DRM-focused record attributes sharply faster Denuvo cracking to hypervisor bypasses but supplies little technical detail [record_id:3013].

## Notable Talks, Records, And Evidence

Several records are particularly important because they represent broad architectural findings rather than isolated bypasses.

The Unicode study is notable for treating evasion as a distributed parsing problem and connecting application, database, browser, WAF, cookie, supply-chain, and LLM effects [record_id:2604]. The stateful syscall-defense proposal is similarly valuable because it identifies three separate failure modes and supplies corresponding design changes rather than only an exploit [record_id:2617].

BTR Reforged is representative of trusted defensive functionality becoming offensive capability. Its duplicate appearance at Black Hat and DEF CON suggests the work is a major part of the 2026 program, although the duplication should not be mistaken for independent confirmation [record_id:2611] [record_id:2866]. Surrogate Ghost is important for its explicit defender guidance—Sigma rules and ETW configurations—as well as its challenge to stable-identifier blocklisting [record_id:2622].

The ARM64 sigreturn records and CET signal research form a coherent body of work showing that exceptional kernel-mediated control transfers remain a weak point in hardware CFI [record_id:2607] [record_id:2863] [record_id:2893]. The shadow-stack record is comparatively strong because it names three separate mechanisms, references real CVEs, and identifies a merged kernel change, though the continued effectiveness of variants still requires external validation [record_id:2911].

Among AI records, the retailer compromise is a strong end-to-end case because it traces a public interface through classifier bypass, prompt disclosure, tool syntax recovery, and backend execution [record_id:2641]. Copilot Studio offers similarly concrete artifacts, including exposed keys, environment data, source code, and a persistent shell [record_id:2925]. LGTM is conceptually important because it shows that a model may classify visible content correctly while remaining unsafe due to missing context [record_id:2871].

SEND is perhaps the collection’s most distinctive research proposal. It broadens evasion metrics beyond whether alerts fired and asks whether defenders reconstructed the operation correctly [record_id:2997]. Its evidence is presently more design-oriented than empirical: the abstract outlines consultation, attack vectors, a consistency engine, and evaluation protocols, but does not report completed controlled experiments.

The facial-recognition and SynthID studies stand out for giving measurable targets. noRecognition claims testing against ten models and 61-plus attack techniques [record_id:2650] [record_id:2889], while the watermark research reports a 104-image held-out set and releases a kit [record_id:3120]. These details make follow-up replication more feasible than for many broad “100% bypass” claims.

## Gaps, Limits, And Open Questions

The largest limitation is source type. Most records are conference abstracts describing future talks, live demonstrations, or unreleased tools. They are evidence of what presenters claim and intend to show, not necessarily proof that the techniques generalize to patched production environments. Duplicate talks—BTR Reforged [record_id:2611] [record_id:2866], noRecognition [record_id:2650] [record_id:2889], ARM64 sigreturn [record_id:2607] [record_id:2893], and counter-UAS [record_id:2746] [record_id:3000]—increase coverage but not independent evidentiary strength.

Evaluation methodology is often underspecified. The mobile-banking and biometric talks report complete bypass rates without identifying the number of distinct applications, SDK versions, configurations, backend checks, or repeated trials [record_id:2884] [record_id:2909]. The Metal-memory record claims “100% evasion” but does not identify which EDR products or detection configurations were tested [record_id:2897]. PhantomShell’s “effectively impossible to firewall” characterization does not discuss traffic normalization, host integrity controls, sequence-analysis anomalies, or link-layer sensor coverage [record_id:3099].

Several open questions recur:

- Can defenders model intent when actions are legitimate administrative API calls, and what identity, approval, and change-management context is needed [record_id:2718]?
- How should security products monitor transient COM registration, signed remediation transactions, GPU-private buffers, package services, and WMI providers without creating prohibitive noise [record_id:2622] [record_id:2862] [record_id:2897] [record_id:2950]?
- Can hardware CFI and shadow-stack designs incorporate signal delivery, fault handling, debugging interfaces, and page-fault mechanisms without breaking compatibility [record_id:2863] [record_id:2911]?
- For AI agents, where should authorization be enforced if model-level guardrails can be bypassed, skipped, or used as an oracle [record_id:2662] [record_id:2925]?
- How should long-horizon agent poisoning be measured, and how long must evaluations run to capture cumulative manipulation [record_id:3103]?
- Can clinical AI systems distinguish authoritative source text from plausible but injected medical claims without relying on semantic conflict [record_id:3082]?
- Does narrative-deception resistance require changes to SOC staffing and runbooks, or can automated causal analysis detect fabricated coherence [record_id:2997]?
- How robust are adversarial textiles under varying cameras, lighting, pose, compression, distance, and model updates [record_id:2650] [record_id:2889]?
- What provenance mechanisms survive regeneration and optimization against surrogate watermark detectors [record_id:3120]?

The village and shorter-session records broaden the scope. Evidence strength varies accordingly. Records naming patches, advisories, concrete datasets, explicit architectures, or released tools offer the best starting points for follow-up. Short abstracts such as the DRM, badge, anti-cheat, and counter-UAS village sessions establish relevant directions but provide limited technical or experimental support [record_id:3013] [record_id:3021] [record_id:3096] [record_id:3000]. Across the collection, downstream researchers should distinguish demonstrations against selected products from evidence of a general defensive failure, and should seek post-conference materials, source releases, vendor advisories, and independent replication before relying on headline success rates.
